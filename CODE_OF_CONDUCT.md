# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, critique ideas rather than people, and keep discussions on topic. Harassment of any kind is not tolerated.

Report unacceptable behaviour privately to the maintainer through the contact details on their GitHub profile, or through the repository's private security reporting channel.
